# Team Availability

A single-page schedule and availability grid for the 2026–2027 season (15 players by default, more can be added).

**Live page:** https://levicaers1-pixel.github.io/team-availability/

- Tap a cell to cycle: – → ✓ Available → ? Maybe → ✗ Not available
- Player names are editable; totals per match are shown at the bottom
- Data is saved in your browser only (localStorage). Use **Export / Import** to move a JSON file between devices or share it

To change the schedule, edit the `EVENTS` array in `index.html`.
